# Happy Healer

An easy, Cure Please style healer for Ashita v4 on CatsEyeXI. It is **Sidekick by Seekey** (MIT) with a simpler window on top: the healing engine and Sidekick's AFK Sleep protection (`lib/core/afk.lua`) are unchanged.

Jobs: WHM, RDM, BRD, COR, SCH, GEO.

Install: copy the `happyhealer` folder into `Ashita/addons/`, then `/addon load happyhealer`. Type `/hh` to show or hide the window, `/hh help` for every command.
